# 水島工場 新事務所｜GitHub公開用データ

このZIPはビルド済みです。Node.jsやライブラリのインストールは不要です。

## 更新方法

1. os_mizushima_factory-github.zip を展開します。
2. 公開リポジトリ os_mizushima_factory の直下へ、展開した「中身」をアップロードしてコミットします。
3. index.html、assets/、data/ がリポジトリ直下に並ぶ構成です。ZIP自体や、その親フォルダーをアップロードする方法では動きません。
4. 既存のGitHub Pages設定を利用します。公開後にブラウザを再読み込みして確認してください。

## 今回の改善

- 「模型を詳しく見る」から、階・屋上・更衣室・3種類の動線を選択。
- 模型の選択と、説明・出典・対応図面・根拠を連携。
- 各階平面図から、その階の3D表示へ戻れます。
- 「全体を見る」で階・屋根・透明度・注釈・視点を初期状態へ戻せます。
- ストーリー復帰では元の再生位置と表示設定を復元。終了後は自由操作へ案内します。
- 選択した階・部位の名称と出典を含むPNG保存。
- 従来の45秒・7シーン、カメラ操作、効果音、添景、動線、表示設定を維持。

開始は01です。音は「音付きで、はじめから」で有効になります。

模型は説明用の概略再構成、動線は模式表現です。用途・配置の根拠と未確認事項を、選択した項目と資料画面で確認できます。

検証の詳細は同梱のIMPROVEMENTS.mdを参照してください。公開サイトへのアップロード自体は今回の作業では実施していません。
